# Сайт компании «menu»

**Демонстрационный сайт** с адаптивным дизайном, посвященный производству премиальных кормов для собак и кошек. Проект реализован с нуля в рамках обучения HTML/CSS.

## Особенности:
Структура: семантичная верстка с использованием тегов `<header>`, `<main>` и т.д.
Технологии: чистый CSS без фреймворков, использование Flexbox и Grid Layout для компоновки блоков.
Адаптивность: корректное отображение на экранах любых размеров благодаря медиа-запросам.

Сайт доступен по адресу https://demjx.github.io/mysite/.

*Данный проект создан исключительно в учебных целях.*
